# Café Crema — Nocturne Espresso Edition (Demo)

Dark-luxury demo website for **Café Crema**, Andheri East, Mumbai ([@cafecrema__](https://www.instagram.com/cafecrema__/)).

Pure HTML + CSS + JavaScript. No build step. All images sit in the root folder.

## Run
Open `index.html` in any browser.

## Staff Portal (admin)
Click **Staff Portal ↗** in the top bar.
- Username: `crema_admin`
- Password: `Crema@2026`

Shows sales, kitchen queue with status updates, table bookings and the menu catalog. Use **＋ Inject Demo Activity** to add sample data.

> Demo only: orders, bookings and login are stored in the browser (localStorage). For real use, connect a backend and server-side login.

## Deploy on GitHub Pages
1. Create a new GitHub repository and upload all files (drag & drop works).
2. Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
